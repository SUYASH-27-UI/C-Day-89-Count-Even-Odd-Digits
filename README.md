# C Day 89 - Count Even and Odd Digits

## Description
This C program counts the even and odd digits in a positive integer.

## Example
**Input:** `123456`

**Output:**
- Even digits: 3
- Odd digits: 3

## Concepts Used
- While Loop
- If-Else
- Modulus Operator
- Counter Variables

## How to Run
1. Save the code as `count_even_odd_digits.c`.
2. Compile it using a C compiler.
3. Run the program and enter a positive number.
